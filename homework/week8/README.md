# 旅行推銷員問題（TSP）五種方法比較


本目錄包含用五種不同方法求解旅行推銷員問題（Traveling Salesman Problem, TSP）的範例程式：

1. 01_greedy_tsp.py - 貪婪演算法（最近鄰點法）
   - 思路：從起點出發，每次選擇距離最近的未拜訪城市
   - 特性：快速、直覺，但只考慮當下，容易非最優

2. 02_improvement_tsp.py - 改良法（局部改善）
   - 思路：從一個初始解（此例用貪婪解）開始，不斷嘗試隨機交換鄰近解並只接受更短的解
   - 特性：簡單的局部搜尋，通常比單純貪婪好

3. 03_hill_climbing_tsp.py - 爬山演算法（Hill Climbing）
   - 思路：隨機初始解，每步只接受改善的鄰近解
   - 特性：貪婪上坡，不接受更差解，易卡在局部最佳

4. 04_simulated_annealing_tsp.py - 模擬退火法（Simulated Annealing）
   - 思路：高溫時以機率接受較差解（跳出局部最佳），隨溫度下降逐漸傾向只接受改善解
   - 特性：探索與利用平衡，較適合組合最佳化問題

5. 05_gradient_descent_tsp.py - 梯度下降法（最陡下降法，離散近似）
   - 思路：每步檢查所有鄰近解（交換），選擇下降幅度最大的方向前進
   - 特性：每步最「徹底」，但計算量大且仍可能卡在局部最佳
   - 備註：TSP屬離散排列問題，真正的連續梯度並不適用，故用最陡下降法作為概念對應


實驗建議
--------
- 調整 random.seed() 觀察不同初始解的影響
- 調整迭代次數、溫度參數（模擬退火）比較結果
- 對比各方法的總長度，體會「接受更差解」對跳出局部最佳的重要性
