# SAT 真值表求解器

本程式實作一個以「窮舉真值表」方式求解 SAT（布林可滿足性）問題的 Python 程式。

## 什麼是 SAT 問題？

SAT（Satisfiability）問題要判斷：是否存在一組布林變數的賦值，讓整個 CNF（合取範式）公式為真。

- **文字（Literal）**：一個變數，如 `A`，或帶否定符號 `~` 的變數，如 `~B`。
- **子句（Clause）**：多個文字以 **OR（∨）** 連接，例如 `A ∨ ~B`。
- **CNF（合取範式）**：多個子句以 **AND（∧）** 連接，例如：

```
(A ∨ ~B) ∧ (~A ∨ C) ∧ (B ∨ ~C)
```

整個公式為真 ⇔ 每個子句都為真。

## 程式結構說明

### 型別別名（第 1-4 行）

```python
from typing import List, Dict, Set
Clause = List[str]   # 子句：文字清單
CNF = List[Clause]   # CNF：子句清單
```

用型別別名讓程式碼更具可讀性。

### `extract_variables(cnf)`（第 7-13 行）

掃描所有子句，收集公式中所有不重複的變數名，並回傳排序後的清單。注意 `~A` 會被視為變數 `A`。

### `evaluate_literal(lit, assignment)`（第 16-20 行）

計算單一文字的布爾值：若是 `~X` 則回傳 `not assignment[X]`，否則直接回傳 `assignment[X]`。

### `evaluate_clause(clause, assignment)`（第 23-25 行）

用 `any(...)` 實作子句的 OR 運算，代表任一文字為真則子句為真。

### `solve_sat_by_truth_table_nobitertools(cnf)`（第 28-79 行）

主體演算法，**不使用 itertools**，改用二進位位元來枚舉所有 `2^n` 種賦值組合：

1. 取得變數清單 `vars_list`，變數個數為 `n`，組合數為 `1 << n`（即 `2^n`）。
2. **位元對映**：用迴圈 `mask` 從 `0` 數到 `2^n - 1`，每個整數的二進位位元代表一個賦值。用 `(mask >> (n - 1 - j)) & 1` 取出第 `j` 個變數的位元，確保表格從 `000`、`001` ... 依序排到 `111`（示範中從 FFF 到 TTT）。
3. **計算結果**：對每個賦值計算所有子句的結果，再用 `all(...)` 判斷整個 CNF 是否為真。
4. 若為真，該組賦值會被加入 `satisfying_assignments`。
5. **輸出**：以表格形式印出每個變數與子句的 T/F 值，最後標出 `★ SAT` 或 `UNSAT`。

### 主程式測試（第 82-90 行）

以公式 `(A ∨ ~B) ∧ (~A ∨ C) ∧ (B ∨ ~C)` 為例執行，印出完整真值表與解。



## 範例輸出

```
[ 變數個數 ]: 3 (共 8 種賦值組合)
-------------------------------------------------------------
  A   |  B   |  C   ||    A ∨ ~B    | ...
-------------------------------------------------------------
  F   |  F   |  F   ||     T        | ...
  ...
-------------------------------------------------------------

結論: SATISFIABLE (可滿足)！找到 2 組解：
  解 1: (A=F, B=F, C=T)
  解 2: (A=T, B=T, C=F)
```

## 時間複雜度

`O(2^n × |CNF|)`：共 `2^n` 種賦值，每種賦值要評估所有子句。變數數量 `n` 較大時會指數爆炸，僅適合教學或小型公式。

## 可改進方向

- 使用 Python `itertools.product([True, False], repeat=n)` 更簡潔地產生組合。
- 改用 DPLL 演算法，利用「單一子句傳播（Unit Propagation）」與「純文字規則」大幅減少搜尋空間。
